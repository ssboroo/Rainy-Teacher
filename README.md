# Багшийн Туслах

Монгол хэл дээрх, офлайнаар ажилладаг Windows desktop апп. Ангийн бүртгэл, ирц, дүн, өргөмжлөл болон шалгалтын материалыг нэг дороос удирдана.

## Боломжууд

- **Ангийн бүртгэл:** олон анги, сурагчдын мэдээлэл, хайлт, CSV импорт/экспорт
- **Ирц:** өдрөөр тэмдэглэх, сарын тайлан гаргах
- **Дүн:** даалгавар, шалгалтын оноо болон хичээл тус бүрийн дундаж
- **Өргөмжлөл:** Монгол хэв маягтай 20 загвар, гарчиг/өнгө/бичвэр засах, сургуулийн лого нэмэх
- **Шалгалтын материал:** олон сонголттой асуулт, зөв хариулт, оноо; хадгалах, дараа нь засах
- **Хэвлэх:** жагсаалт, тайлан, сурагчийн шалгалт, хариултын түлхүүр, өргөмжлөлийг хэвлэх эсвэл PDF болгох
- **Нөөц хуулбар:** мэдээллийг локал SQLite санд хадгалж, `.db` файл болгон нөөцлөх

Интернэт холболт шаардлагагүй. Сурагчдын мэдээлэл тухайн Windows компьютерт хадгалагдана.

## Windows дээр ажиллуулах

Python 3.10+ суулгасан компьютер дээр:

```bat
py bagshiin_tuslah.py
```

Ганц `.exe` файл үүсгэх бол `build_windows.bat` ажиллуулна. Файл `dist\БагшийнТуслах.exe` дотор үүснэ.

GitHub Actions нь `main` салбар руу push хийх бүрд Windows executable-ийг build хийж artifact болгон хадгална. `Actions → Build Windows app` дотроос татна.

## Өгөгдлийн байршил

```text
%APPDATA%\BagshiinTuslah\bagshiin_tuslah.db
```

Компьютер солихоос өмнө аппын **Нөөц хуулбар** товчийг ашиглаарай.
