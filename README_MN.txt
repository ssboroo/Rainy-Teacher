БАГШИЙН ТУСЛАХ — Windows desktop апп
======================================
Хувилбар: 1.5.1

ОФЛАЙН ҮНДСЭН БОЛОМЖУУД
- Анги сонгох болон шинээр анги үүсгэх
- Сурагчийн код, нэр, эцэг эх/асран хамгаалагч, утас, тэмдэглэл хадгалах
- Ирцийг огноогоор тэмдэглэх: Ирсэн, Өвчтэй, Чөлөөтэй, Тасалсан
- Хичээл, шалгалт/даалгавар, авсан болон нийт оноогоор дүн хөтлөх
- Сурагчдын жагсаалт, ирцийн тайлан, дүнгийн тайланг урьдчилан харах
- Хэвлэх цонхоос принтер сонгох эсвэл PDF болгон хадгалах
- Өргөмжлөл, батламж, талархлын 20 Монгол загварыг засварлах, PNG/JPG лого оруулах; хөх-алтлаг хээтэй загварыг PDF болгон хэвлэх
- 20 загварыг хээ, өнгөтэй нь preview цонхоор хараад сонгох
- Слайд үүсгэх, хадгалах, засах 10 Canva маягийн Монгол загвартай Presentation студи
- Presentation-ийг 16:9 слайд хэлбэрээр хэвлэх эсвэл PDF болгон хадгалах
- Өргөмжлөлийг хадгалах, дараа нь дахин нээж хэвлэх
- Сонгох тест үүсгэх, дөрвөн сонголт, зөв хариулт, оноо оруулах
- Шалгалтын материалыг хадгалах, засах, сурагчийн хувилбар болон хариултын түлхүүр хэвлэх
- Сурагчдын мэдээллийг CSV импортлох, Excel-д нээж болох CSV болгон гаргах
- Өгөгдлийн санг нөөц файл болгон хадгалах
- Өгөгдөл тухайн компьютерт хадгалагдана; интернэт шаардахгүй

АШИГЛАХ
1. RainyTeacher-Setup-1.5.1.exe суулгагчийг ажиллуулна.
2. Баруун дээд талын “+ Анги” товчоор анги үүсгэнэ.
3. “Сурагчид” хэсгээс сурагчдаа бүртгэнэ.
4. “Ирц”, “Дүн” хэсэгт өдөр тутмын мэдээллээ оруулна.
5. “Өргөмжлөл” хэсгээс загвар сонгож бичвэр/өнгө засах, лого оруулах, хадгалах эсвэл хэвлэх.
6. “Шалгалтын материал” хэсгээс шалгалт үүсгэж, асуултаа нэмэн хадгална. Жагсаалтаас засаж, хэвлэж болно.
7. “Танилцуулга” хэсгээс 10 загварын нэгийг сонгож, слайдаа бичээд хадгалах эсвэл PDF болгон хэвлэнэ. Дараагийн слайдыг `---` мөрөөр тусгаарлана.
8. “Тайлан ба хэвлэх” хэсгээс бүртгэлийн тайлангаа сонгоно.

Өгөгдлийн байршил:
%APPDATA%\BagshiinTuslah\bagshiin_tuslah.db

НӨӨЦ ХУУЛБАР
Зүүн талын “Нөөц хуулбар” товчийг дарж .db файл болгон хадгална.
Компьютер солиход нөөц файлаа шинэ компьютер рүү хуулж хадгална.

WINDOWS ДЭЭР BUILD ХИЙХ
Python 3.10+, Inno Setup суусан Windows 10/11 дээр build_windows.bat файлыг ажиллуулна.
dist\RainyTeacher.exe portable хувилбар болон
dist-installer\RainyTeacher-Setup-1.5.1.exe суулгагч үүснэ.

Суулгагч Start цэсэнд shortcut үүсгэж, хүсвэл desktop shortcut нэмж болно.
Аппын өгөгдөл хэрэглэгчийн AppData дотор хэвээр хадгалагдана.
